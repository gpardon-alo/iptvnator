# Tournament artwork

These PNGs identify the public tournaments in Discovery's Sports selector.
`sources.json` records each league page and the downloaded image URL from
[TheSportsDB](https://www.thesportsdb.com/). Artwork is bundled so the selector
works without third-party runtime requests. Tournament names and logos remain
the identifying marks of their respective owners.

The matching aliases and labels are maintained in
`libs/workspace/discovery/feature/src/lib/discovery-leagues.ts`.
